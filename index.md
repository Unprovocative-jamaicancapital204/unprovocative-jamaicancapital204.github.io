## 🔍 Troubleshooting Common Issues

### 😟 "My PDF isn't compiling"

Don't panic! This is usually easy to fix:

- **Check for red underlines** in your code—these indicate errors
- **Look at the error panel** at the bottom of the screen
- **Maleficium will tell you** exactly what went wrong and where
- **Fix the error** and compile again

### 📎 "I can't find my downloaded packages"

Maleficium uses Tectonic, which handles packages automatically:

- **No need to install packages** manually
- Tectonic downloads what you need **as you work**
- This happens **in the background** so you never have to worry about it

### 🖥️ "Maleficium is running slowly"

Try these quick fixes:

- **Close unnecessary tabs** you're not using
- **Break large documents** into smaller files
- **Restart Maleficium** to clear any temporary issues
